# QR Code Images

## Missing Files

The following QR code images need to be added to the `/public` folder:

1. **qr-catalogue.png** - QR code linking to: https://www.canva.com/design/DAGZv_IU6ps/...
2. **qr-info.png** - QR code linking to: https://www.canva.com/design/DAGZwB_V0vg/...

## How to Generate QR Codes

You can generate these QR codes using:

- https://www.qrcode-monkey.com/
- https://www.qr-code-generator.com/
- Or any QR code generator tool

### Steps:

1. Generate QR codes for the Canva URLs
2. Save them as PNG files
3. Place them in the `/public` folder with names:
   - `qr-catalogue.png`
   - `qr-info.png`

## Recommended Size

- 512x512 pixels or larger
- PNG format with transparent background (optional)
